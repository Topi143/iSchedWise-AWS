# iSchedWise V4 Promo Voiceover Script

## Target Duration
- 75 to 90 seconds

## Full Script
Scheduling should be simple.

Meet iSchedWise V4, an academic scheduling system for schools.

Create class and exam schedules in a few easy steps.

As you plan, iSchedWise checks for faculty, room, and time conflicts right away, so you can fix problems early.

Manage faculty workloads, match assignments to availability, and keep schedules fair across departments.

See room and building availability in real time and use every slot better.

With role-based access, Admins see everything, while Deans manage only their approved scope.

Need old records? Archive them safely and restore them when needed.

When it is time to report, export clear Excel and PDF files in seconds.

Need extra help? Optional AI suggestions can speed up planning.

iSchedWise V4. Plan smarter. Schedule better.

## Delivery Notes
- Pace: calm and confident, medium-fast
- Tone: operational clarity, not hype-heavy
- Recommended speaking speed: 130 to 150 words per minute
- Leave a short pause after each feature section for screen focus
