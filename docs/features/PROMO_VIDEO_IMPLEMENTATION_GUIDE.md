# iSchedWise V4 Promo Video Implementation Guide

## Presentation Style Goal
Create a 75 to 90 second promo that feels like a clean PowerPoint presentation in motion: clear sections, headline-driven scenes, smooth transitions, and readable callouts for decision-makers.

## Audience
- School administrators
- Department deans
- Academic scheduling staff

## Visual Direction (PowerPoint-Inspired)
- Use slide-like chapter flow with a headline on each scene.
- Keep one message per scene.
- Use consistent lower-third style for feature labels.
- Use simple motion: fade, push, or zoom-in emphasis only.
- Keep spacing clean and text large enough for mobile preview.

## Slide Deck Storyboard (75 to 90s)

- Headline on screen: Scheduling should not feel like chaos.
- Visual: Spreadsheet overload, quick cuts, stressed planner.
- Presenter intent: Establish urgency.

	- Rooms and Buildings
	- Access Control
	- Archive
	- Export
	- AI Suggestions

## Subtitle Source
- Use timed subtitles from [docs/features/PROMO_VIDEO_SUBTITLES_90S.srt](docs/features/PROMO_VIDEO_SUBTITLES_90S.srt).

## Audio and Edit Guidance
- Music: modern corporate pulse, light percussion, no aggressive drops.
- Voiceover: calm, clear, executive tone.
- SFX: very light UI click accents only.
- Highlights: use subtle focus boxes for critical actions.
- Recording: stable captures, zoom only on key controls.

## Production Checklist
- Capture real product screens only (no placeholder UI).
- Keep each feature clip under 10 seconds.
- Verify subtitle timing against final voiceover.
- Ensure all text is readable on mobile preview.
- Export one 1920x1080 landscape master.
- Export one 1080x1920 vertical cutdown.
- Deliver one full-length version and one 30-second cutdown.
